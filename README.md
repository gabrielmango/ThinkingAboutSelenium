# Curso de Selenium WebDriver

## 📚 Sobre o Curso

Este repositório contém o material desenvolvido durante o curso prático sobre `selenium.webdriver.support.expected_conditions`, focado em ensinar como trabalhar com condições de espera explícitas em automação de testes com Selenium WebDriver.

## 🎯 Objetivos

* Aprender a usar condições de espera explícitas (*Expected Conditions*) para criar testes mais robustos
* Dominar as principais condições de espera do Selenium
* Desenvolver habilidades para lidar com elementos assíncronos em páginas web
* Criar testes automatizados mais confiáveis e menos propensos a falhas por timing
